# Yomizora (読み空) — Android-приложение для чтения на японском языке

**Скачать актуальный APK (v1.1.1):**
- Прямая загрузка из репозитория: [apk/yomizora-latest.apk](https://github.com/Nqam/yomizora-reader/raw/main/apk/yomizora-latest.apk)
- Страница релизов: [GitHub Releases](https://github.com/Nqam/yomizora-reader/releases/latest)

**Yomizora** — полностью офлайн Android-приложение для практики чтения японских текстов уровней **JLPT N5** и **JLPT N4** с корректной фуриганой, встроенным русско-японским словарём, проверкой понимания и системой последовательного прогресса.

## Возможности

- **110 уникальных японских текстов** на старте (55 JLPT N5 + 55 JLPT N4) в 11 категориях.
- **Настоящая фуригана над иероглифами** с контекстным чтением и поддержкой 3 режимов (`Кандзи + фуригана`, `Только кандзи`, `Только кана`).
- **Интерактивный офлайн-словарь**: нажатие на слово открывает карточку с чтением, частью речи, переводом на русский язык и возможностью сохранить слово.
- **Проверочные вопросы (1–3 вопроса)** после каждого текста: следующий материал открывается только после правильных ответов на все вопросы.
- **Полная офлайн-работа**: никаких серверов, аккаунтов и обязательных сетевых запросов.
- **Гибкие настройки чтения**: размер шрифта, межстрочный интервал, светлая и тёмная темы.
- **Независимый прогресс по уровням**, избранные тексты, личный словарь, поиск и фильтрация.
- **Расширяемость без перекомпиляции**: импорт новых JSON-пакетов контента и экспорт резервной копии прогресса прямо в настройках.

## Технологический стек

- **Kotlin** 2.0.21, **Jetpack Compose** + **Material 3**
- **Hilt** (DI), **Room** (две независимые БД: контент и прогресс), **DataStore Preferences**
- **Kotlin Coroutines & Flow**, **Kotlinx Serialization**, **Navigation Compose**
- **Min SDK**: 26 (Android 8.0), **Target SDK**: 35 (Android 15)

## Как открыть и собрать проект

1. Откройте папку проекта в **Android Studio** (Ladybug или новее) или используйте командную строку.
2. Убедитесь, что в `local.properties` указан путь к Android SDK (`sdk.dir=...`).
3. Сборка APK из командной строки:
   ```bash
   ./gradlew assembleDebug
   # или релизная сборка:
   ./gradlew assembleRelease
   ```
4. Готовый APK будет находиться в:
   - `app/build/outputs/apk/debug/app-debug.apk`
   - `app/build/outputs/apk/release/app-release.apk`

## Как установить приложение на Android

Через ADB:
```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```
Либо скопируйте `.apk` на смартфон и откройте его через файловый менеджер.

## Тестирование и проверка контента

Запуск модульных тестов (включая валидацию всех 110 стартовых текстов, проверку фуриганы, уникальности и логики блокировки):
```bash
./gradlew testDebugUnitTest
```

Для генерации и валидации стартовых пакетов из исходников:
```bash
python tools/generate_packs.py
```

Подробная инструкция по добавлению новых материалов описана в [CONTENT_GUIDE.md](CONTENT_GUIDE.md), а пример пакета — в [examples/sample_content_pack.json](examples/sample_content_pack.json).
